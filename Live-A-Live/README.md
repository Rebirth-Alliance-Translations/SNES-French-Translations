## Installation

1. Utiliser une copie personnelle de la ROM japonaise originale **sans en-tête de 512 octets**.
2. Vérifier son SHA-256 : `415623707065646b427bdc5430cb0037fbf9dccd4b04cbf0b08e879dbe3e7210`.
3. Appliquer `Live_A_Live_FR_RAT_2026_JP_vers_FR_COMPLET.ips` à l'aide de Flips (Floating IPS).
4. Tester le résultat sur émulateur ou matériel compatible.
