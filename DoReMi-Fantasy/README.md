# DoReMi Fantasy — Traduction française (Rebirth Alliance Translations)

**Plateforme :** Super Famicom / Super Nintendo  
**Version :** française 1.3 — RAT 2026  
**Distribution :** patch IPS uniquement (aucune ROM incluse)

## Contenu

- Traduction française du jeu.

## Installation

1. Disposez d'une copie légale de la ROM japonaise d'origine, sans en-tête de 512 octets, de **2 097 152 octets**.
2. Vérifiez son empreinte SHA-256 : `b7209ec3a5a0d28724f5867343195aef7cb85aeb453aa84a6cbe201b61b0d083`.
3. Appliquez `DoReMi_Fantasy_FR_1_3_RAT_2026_JAP_vers_FR.ips` avec un utilitaire IPS compatible.
4. Le fichier résultant mesure **2 621 440 octets** et doit avoir pour SHA-256 : `cf27aedcddb3ce4e3d814d950170ffa99921e006406737ce2f7b55a4b19363e4`.

**Attention :** ne pas appliquer ce patch sur une ROM déjà traduite ou déjà modifiée.
