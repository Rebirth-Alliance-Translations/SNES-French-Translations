## Installation

**ROM requise : version japonaise originale de Clock Tower (Super Famicom), non modifiée et sans en-tête de copie.** Le patch ne s'applique **pas** à une ROM française déjà modifiée.

1. Ouvrez [Floating IPS (Flips)](https://www.romhacking.net/utilities/1040/) ou un autre outil compatible IPS.
2. Sélectionnez **Apply Patch**.
3. Choisissez `Clock_Tower_FR_1_5_RAT_Complet_JP_vers_FR.ips`.
4. Sélectionnez votre ROM japonaise originale compatible.
5. Enregistrez la ROM patchée sous un nouveau nom, puis lancez-la dans votre émulateur ou sur votre matériel compatible.
